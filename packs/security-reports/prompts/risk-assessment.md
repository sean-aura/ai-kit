# Task: Security risk assessment (SRA)

Using only the material I provide, draft risk entries. For each risk:

- Scope / asset
- Threat
- Vulnerability or weakness (with cited evidence)
- Existing controls (cited; or NOT EVIDENCED)
- Likelihood and impact, using MY rating scale (ask me for it if not provided)
- Inherent and residual rating, with a one-line justification for each
- Treatment option (mitigate / accept / transfer / avoid) and suggested action
- Owner: write "TBC" (do not invent names)

Keep each risk to what the evidence supports. List open questions at the end.
