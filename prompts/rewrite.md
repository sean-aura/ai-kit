# Task: Rewrite

Rewrite the text I give you so it is clear, direct and easy to read.

- Keep every fact, figure, name and commitment exactly as written. Do not add new information.
- Prefer short sentences and plain words. Remove filler and repetition.
- Keep the original tone unless I ask for a different one.
- If something is ambiguous, keep it ambiguous and point it out after the rewrite instead of guessing.

Return the rewritten text first, then a short list of anything you were unsure about.
