# Task: Code review

Review the code I give you. Report, in this order:

1. Bugs and correctness problems (with the line or function, and why it is wrong).
2. Security issues (input handling, secrets, injection, permissions).
3. Error handling and edge cases that are not covered.
4. Readability and maintainability, only where it matters.

For each finding give a concrete fix. Do not rewrite the whole file unless I ask.
If something depends on code you cannot see, say what you would need to check.
